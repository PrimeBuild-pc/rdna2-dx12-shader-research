## Il mapping era corretto; il difetto è nel controllo a blocchi

`benchmark_2026-09-08_21-08-37` è la run giusta (1280×720, `windowMode` 2, dentro la finestra di cattura 21:08:06–21:11:03). Ho trovato la finestra del benchmark dentro il CSV senza usare la correlazione:

|---|---|
| prima riga | **6416** (QPC 27615576.4577, ft 4.6158) |
| ultima riga | **18357** (QPC 27679834.8393, ft 6.9018, `DisplayedTime` 110.01 → fine benchmark) |
| conteggio | 18357 − 6416 + 1 = **11942** = esattamente `frameNumber` nativo ✓ |
| durata QPC | 64258.38 ms su 11941 intervalli; attesa da `sum(y) − y[-1]` ≈ 64260.3 ms → **scarto 1.9 ms (0.003%)** ✓ |

Quindi **la traccia è completa**: nessun evento ETW perso, nessun present in eccesso, nessun disallineamento reale. Il frame-for-frame esiste ed è a offset **6416**.

**Causa del fallimento:** `size = min(1000, len(y) // 3)` è un conteggio **fisso di frame**, quindi una finestra temporale che si accorcia al salire degli FPS — 8.9 s a 1440p, 6.1 s a 1080p, **5.4 s a 720p**. Il rumore di pacing fra `MsBetweenPresents` e il frame time interno del gioco è ~costante in ms assoluti, quindi pesa sempre di più su frame sempre più corti. Si vede nei dati già acquisiti: correlazioni di blocco 0.875/0.946/0.888 a 1440p → **0.783**/0.849/0.839 a 1080p. A 720p un blocco è finito su un picco rivale. Il controllo si indebolisce esattamente dove servirebbe più forte.

Non è un falso positivo da aggirare abbassando una soglia: è il controllo dimensionato male.

## Patch — `tools/c2077_native.py`

Due modifiche. Blocchi come **frazione della traccia** (invariante alla risoluzione, e i tre blocchi ora coprono tutto invece del 25%), e un **localizzatore indipendente** che non usa correlazione — quello che ho appena fatto a mano.

**`match()`, righe 15-28** → aggiungi il margine del picco:
```python
def match(x, y, guard=50):
    if len(y) < 2 or len(x) < len(y) or not np.isfinite(x).all() or not np.isfinite(y).all():
        raise ValueError("Incomplete or nonfinite frame trace")
    n = len(y)
    s = np.r_[0, np.cumsum(x)]
    q = np.r_[0, np.cumsum(x * x)]
    variance = np.maximum(q[n:] - q[:-n] - (s[n:] - s[:-n]) ** 2 / n, 0)
    den = np.sqrt(variance * np.sum((y - y.mean()) ** 2))
    r = np.divide(np.correlate(x, y - y.mean(), mode="valid"), den,
                  out=np.full(len(x) - n + 1, -np.inf), where=den > 0)
    if not np.isfinite(r).any():
        raise ValueError("No identifiable frame pattern")
    a = int(np.argmax(r))
    rival = np.r_[r[:max(0, a - guard)], r[a + guard + 1:]]
    rival = rival[np.isfinite(rival)]
    return a, float(r[a]), (float(r[a] - rival.max()) if rival.size else None)
```

**Nuova funzione**, subito dopo `match`:
```python
def qpc_locator(d, n, target_ms):
    """Localizza la finestra col tempo assoluto QPC invece che con la forma della traccia.

    Non condivide nessuna ipotesi col pattern matching: cerca l'unica finestra di n righe
    consecutive la cui durata combacia con quella dichiarata dal gioco. Se i due metodi
    concordano, l'allineamento non dipende piu' dalla correlazione.
    """
    if "CPUStartQPCTime" not in d.columns:
        return None, None
    q = pd.to_numeric(d["CPUStartQPCTime"], errors="coerce").to_numpy(float)
    if not np.isfinite(q).all():
        return None, None
    span = q[n - 1:] - q[:len(q) - n + 1]
    b = int(np.argmin(np.abs(span - target_ms)))
    return b, float(span[b] - target_ms)
```

**`analyze()`, sostituisci righe 47-55** (da `a, correlation = match(x, y)` fino al `raise` dei blocchi):
```python
    a, correlation, margin = match(x, y)
    # ponytail: frame-for-frame matching requires a complete trace; dropped ETW events fail closed.
    # Il blocco era min(1000, len(y)//3): un CONTEGGIO fisso di frame, quindi una finestra
    # temporale che si accorcia al salire degli FPS (8.9 s a 1440p, 5.4 s a 720p) proprio dove il
    # jitter di pacing pesa di piu' su frame piu' corti. A 720p il controllo si e' rotto da solo su
    # una traccia completa e allineabile. Un terzo della traccia e' invariante alla risoluzione e i
    # tre blocchi la coprono tutta senza sovrapporsi.
    checks = []
    size = len(y) // 3
    for offset in (0, len(y) // 2 - size // 2, len(y) - size):
        pos, score, block_margin = match(x, y[offset:offset + size])
        checks.append(dict(native_offset=offset, presentmon_row=pos, correlation=score,
                           peak_margin=block_margin))
        if pos - offset != a:
            raise ValueError(f"Independent block alignment disagrees: {checks}")
    qpc_row, qpc_delta_ms = qpc_locator(d, len(y), float(y.sum() - y[-1]))
    if qpc_row is not None and abs(qpc_row - a) > 2:
        raise ValueError(f"QPC locator {qpc_row} disagrees with pattern match {a}")
```
